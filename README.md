# mooc-quiz-skill

一个给 [豆包电脑版](https://www.doubao.com/) 用的自定义 Skill（技能），用于在中国大学 MOOC（icourse163）等网课平台自动完成**已登录用户本人的单元测验 / 课后练习**闭环：读题 → 作答 → 提交 → 看分 → 进模拟器看错题 → 重答直到满分。

> ⚠️ **合规声明**：本 Skill 仅限你本人已登录、平台开放的课后练习/单元测验，**不得用于正式考试、期中期末、替人代考**。使用前请确认你所在课程的测验允许自主练习。

## 它解决什么痛点

MOOC 单元测验通常有 3 次提交机会取最高分，但网页端提交后**看不到每题对错**，只能看到总分。这个 Skill 固化了一套经过多门课程实测的闭环流程：

- 网页端负责读题、作答、提交、看分
- MuMu 模拟器（手机 App 版）只用来**回看答卷上的绿勾/橙叉标记**，定位错在哪
- 按错题记录重答，3 次机会内冲满分

核心经验全部沉淀在 `SKILL.md` 里，包括：选项随机换位按内容作答、判断题 ✓/× 位置确认、多选漏选语义评估、并发限制弹窗处理、ADB 通道只看错题不答题（有漏题风险）等。

## 依赖

- 豆包电脑版（Windows），支持自定义 Skill 加载
- MuMu 模拟器（Windows），已安装并登录中国大学 MOOC App
- 浏览器自动化：豆包内置的 `computer_use_tool(plane="bu")`
- Python 3（可选，用于跑 `mumu_adb_helper.py` 做 ADB 自动判读；手动看答卷不需要）

## 安装

把整个文件夹复制到豆包的用户 Skill 目录：

```
豆包工作目录/.user_skills/mooc-quiz-skill/
├── SKILL.md
├── mumu_adb_helper.py   (可选)
└── references/          (预留)
```

重启豆包会话后，说"帮我做 MOOC 测验"即可触发。

## 目录说明

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 完整流程定义、铁律、门禁、判读规则（41KB，核心资产） |
| `mumu_adb_helper.py` | 可选辅助脚本：通过 ADB 自动 dump UI、定位元素、判读绿勾/橙叉标记 |
| `references/` | 预留的参考资料目录 |

## 工作流程速览

```
第0步 预检 → 分 A组(0/3全新) / B组(≥1/3有历史)
第0.5步  B组先在 MuMu 看历史答卷错题
第1轮   网页端一口气答完所有待做
第1次 MuMu 集中看本轮未满分答卷
第2轮   带错题记录重答
第2次 MuMu 看新错
第3轮   最后一次机会 → 结束
```
